# Synthetic import fixtures

Original RTSEngine test data: Unity Force Text prefab variants/scene combat, Unity 2D sprites and
explicit Tilemap, Godot 4 2D/3D scene/script overrides, and a neutral Unreal export. No external game
assets. `unreal/rock.fbx` is a copy of the hand-written CC0 `tests/data/models/cube.fbx` (license
and authorship are recorded in that file). Tiny Unity tile texture was generated for these tests.
