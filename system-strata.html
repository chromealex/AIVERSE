Engine systems / STRATA

STRATA

since 3.0.0

Virtualized geometry

Huge meshes without hand-made LODs: paged streaming, clusters with crack-free detail transitions and GPU culling on Metal and Vulkan.

in development since Nov 19, 2026

System docsDevelopment diary · 3

What is inside

Builder

Mesh clustering, an LOD hierarchy and seam certification.

LOD selection

Per-view detail selection with hysteresis, on CPU and GPU.

Residency

Index pages with a memory budget, asynchronous disk loading, several worlds.

Rendering

Drawn through the existing Renderer3D; GPU culling on Metal and Vulkan, indirect drawing on Vulkan.

Tools

An agent skill and asset analysis through MCP.

Debug view

Colouring of selected clusters by id, LOD level, error or material; presentation only.

Read more →

What it lets you do

  • Put huge meshes in a scene without hand-made LODs.
  • Keep geometry in memory within a budget and stream it in pages from disk.
  • Switch detail without cracks between clusters and without flicker.
  • Check whether an asset fits before import — through MCP.
