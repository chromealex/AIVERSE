## Boundaries
This is S6a, not global project-history completion. CompoundEdit is owner-thread synchronous and assumes participants call beginEdit before mutation; no nested compound scopes, document replacement, save or external side effects inside a batch. It is not a transaction over project rules, manifest, assets, external files, runtime state or arbitrary plugin callbacks. Selection/logging and non-map effects are not part of MapData rollback. Legacy cross-frame brush grouping and agent history positions are not fully solved; add explicit stroke ownership and versioned agent history targets next. Existing snapshot cap is an estimate, not a measured allocation bound. No new native dependency, simulation authority, persistence format or graph owner. Existing Workspace/MCP map operations share MapDoc; this stage does not add a separate MCP transaction command.
