## Acceptance and limitations
Measured wall time after readiness and through tick increment includes command processing, system execution and each system's ECS flush. Not worker CPU time, not renderer timing, not network latency or end-to-end frame time. Nominal interval is not a measured CPU allocation. No per-system entity count instrumentation. No sample persistence or new authoritative state. Capture history disappears with simulation replacement and may count replayed steps if a native consumer uses the generic API during rollback. Studio restricts capture to controllable local matches. Profiling overhead not measured; disabled path retains a small capture check. Closing the panel does not cancel the finite native capture; reopen to rediscover. Paused capture waits until resumed/stepped/stopped. Explicit user operation starts profiling, not status polling. No new library, graph, scene/inspector mutation, save format or platform-specific implementation. Existing headless native profiling interface preserved; new Studio bridge is not a remote MCP operation.
