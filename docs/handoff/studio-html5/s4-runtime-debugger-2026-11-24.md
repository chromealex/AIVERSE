## Boundaries
First owner-approved editable fields only. Energy requires positive configured max. Zero HP, resurrection, arbitrary native components, Transform/Owner, region identities, physics, inventory and structural changes remain read-only until owner-specific validated adapters exist. Existing authoring writeback is separate. Runtime debug changes are immediate between local ticks, not replay commands; command-only replay cannot reproduce them. The marker is session-local, not persisted; replay exports are not globally blocked. No claim of save/load or remote authoritative mutation support. Stop/restart discards the hosted session; explicit existing Keep Play Changes is a separate authoring action. This stage does not add new simulation authority, ECS schema, graph or dependency.
