## Implementation
- StudioTextResourceRepair.h: exact typed byte-span replacement for OBJ mtllib and renderer-supported MTL texture commands. Preserves non-slot content, options, CRLF and whitespace. Each MTL slot is interpreted relative to its consuming OBJ as in ModelObj.cpp. Shared MTL demands from all discovered consumers must agree; incompatible paths refuse before mutation. Wavefront texture paths containing whitespace are refused because existing loader consumes the last token.
- COLLADA library_images/image/init_from or ref leaf slots use source offsets from the existing engine XML parser. Preserves other XML, attributes and namespace declarations. Round-trippable UTF-16 LE/BE with BOM supported via strict re-encoding; UTF-8 text preserved. Mixed-markup leaf rewrites refuse rather than erase markup. No arbitrary XML reserialization.
- Existing asset dependency planner tracks physical repair document for Wavefront, reprojects URI owners and targets, applies text repairs with existing bounded history and directional payload digests; exact undo/redo snapshots and semantic slot comparison. Move journal v7 and binary-safe snapshots support these formats; older journals remain readable. UI repair message generalized; linked MCP uses same native owner.
- Regression scenarios for moving texture, moving OBJ, CRLF/options preservation, DAE UTF-16 roundtrip, shared-library conflict refusal; existing test target reused. Skill/MCP docs updated.

## Evidence / limits
GitHub commits pushed and read back. C++ build, CTest, TypeScript build, actual MCP transport, UI and recovery test execution NOT RUN. No main merge. Automatic repair covers known loader slots only, lowercase extensions and bounded snapshots (4 MiB aggregate per direction, 8 MiB paired). Does not support arbitrary FBX/legacy formats, dynamic dependencies, MTL cloning to resolve incompatible consumers, unsupported Wavefront texture names, mixed-markup DAE leaves, non-roundtrippable encodings, or arbitrary external writers.
