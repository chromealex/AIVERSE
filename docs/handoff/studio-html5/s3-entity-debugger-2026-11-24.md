Dormant is actual marker presence only. Native extensions may still emit their own numeric references; unsafe numeric-only links are not followed. Legacy $entity consumers unchanged. Existing component list indexes only catalogued components; detail includes actual native extension readers and schemas. Existing WorldInspect uses mutable reads in other legacy readers and may trigger ECS change notifications; this stage does not claim to make the entire inspector const or replace those readers. Existing 750ms model rebuild polling remains; performance on large worlds not measured. New native diagnostics use const reads; no full ledger rebuild for each row.
