# Scene — доработки

Одна ветка на всё, что найдено на вкладке Scene. В неё входят Hierarchy, Project, вид Scene, Game, Inspector и History.

## Делаем

1. Масштаб текста редактора. Сделано. Ползунок больше не увеличивает страницу.
   На Hierarchy шрифт 10–12 пикселей, отдельной настройки размера нет.
   Ползунок UI scale ставит `zoom` на весь документ: страница вылезает за монитор, а трёхмерный вид считается без этого зума и разъезжается с панелями.
   Нужно: текст растёт внутри текущего окна, окно движка остаётся на мониторе, сцена не сдвигается.

2. Пресеты раскладки. Список вынесен в кнопку Layout в шапке, отдельно от масштаба.
   Крупные кнопки из Editor settings убраны. Меню: имена раскладок, линия, Save Layout, файл, Delete, Reset All.
   Клик по имени применяет и закрывает. Клик снаружи только закрывает.
   Вкладку тянут мышью. Подпись вкладки не начинает системный drag, Scene на время броска прячется,
   иначе курсор над её окном обрывает жест. Куда отпустить, считается по прямоугольникам панелей.
   Проверено в запущенном AiverseStudio: Hierarchy ушла в свою колонку между Project и Scene.
   Кнопки свернуть, развернуть и закрыть закреплены у правого края шапки.
   Если вкладки рабочих пространств не помещаются, лишние уходят в меню у шеврона, а не обрезаются.

3. Закрытие вкладки колесиком мыши. Сделано.
   Сейчас вкладка закрывается только крестиком. Нажатие на колесико ничего не делает.
   Нужно: щелчок колесиком по вкладке закрывает её, как в браузере.

4. Правый клик по вкладке: разделитель и Add Tab. Сделано.
   Сейчас меню: Open in New Window, Close, Split Right / Left / Down / Up. Линия перед Split почти не видна.
   В Unity после Close идёт разделитель и Add Tab со списком вкладок, которые встают в эту же стопку.
   Такая команда уже лежит в `stash@{1}` (`EditorTabCommands`): «Закрыть вкладку» и «Добавить вкладку» для project / stats / console. Это старый ImGui-редактор, в HTML её не переносить как есть.
   Нужно: заметный разделитель и пункт Add Tab. Выбранная панель открывается в той стопке, по которой кликнули.

## Окно Windows

5. Верхняя полоса окна. Клиентская область занимает всё окно: `WM_NCCALCSIZE` не оставляет место под системную шапку.
   Стили сворачивания остаются, чтобы работали прилипание и панель задач.
   Тянуть окно — за пустое место тёмной шапки (`SC_MOVE`). Размер — за внешние пиксели края:
   страница сама ведёт край по таймеру, пока кнопка зажата, и сцена меняет размер сразу, не после отпускания.
   Вкладку можно вытащить за край окна: открывается своё окно с тёмной шапкой. Закрытие или бросок этого окна
   на главное возвращает вкладки в док. Проверено: Project ушёл в отдельное окно и открылся снова после запуска.

6. Меню Window закрывается от колесика. Сделано.
   Список длинный и должен прокручиваться внутри себя. Сейчас любой `wheel` закрывает меню (`StudioContextMenu`), поэтому до нижних пунктов не добраться.
   Нужно: колесико над меню листает список. Закрытие остаётся по клику снаружи и по Escape.

7. Наполнение меню Window. Сделано.
   Сейчас сначала все панели в порядке списка, потом Workspaces, потом команды.
   Нужно сверху вниз: Workspaces, разделитель, системные команды (Reset Layout, Command Palette, Welcome Tour), открытые на этой вкладке окна с галочками, затем остальные окна фич по алфавиту.
   На Windows у Workspaces и команд рисуется знак ⌘. Там должен быть Ctrl.

8. Системная иконка окна. Знак AIVERSE из `engine/assets/branding/mark.png`, размеры 16–256, прозрачный фон сохранён.
   Первый вариант был один кадр 32×32 без альфы, поэтому в Пуске был чёрный мыльный квадрат.

9. Узкая колонка. Кнопки в ряд больше не сжимаются друг на друга: не влезли — встают столбиком.
   Шапка панели (название и Open) тоже. Подписи карт переносятся, а не обрезаются посередине буквы.

10. Меню Layout больше не гасит всю сцену. Трёхмерный вид лежит поверх страницы, поэтому раньше
    любое меню, задевшее панель, прятало вид целиком — оставалась тёмная дырка. Теперь вид уступает
    только угол под меню, остальная сцена остаётся. Окно на весь вид (диалог, палитра команд) по-прежнему
    прячет вид, иначе оно оказалось бы под ним. Проверено: меню открыто, карта на месте, пункты читаются;
    после Escape сцена снова занимает всю панель.
