# VIVID authored LOD preparation — 2026-11-21

VIVID imports use the shared renderer's existing aiverseLods chains, including
skinned/morphed semantic remapping and screen-size selection. This stage adds
configure_lods.cjs to connect already-authored part meshes, and Creator --lod
 auto|highest to compare automatic selection against source detail. Studio keeps
existing automatic renderer selection. No new UI or save schema.

Example config:
```json
{"version":1,"chains":[{"source":"face_LOD0","levels":[{"mesh":"face_LOD1","maxPixels":500},{"mesh":"face_LOD2","maxPixels":200}]}]}
```
Run `node tools/vivid-dna-import/configure_lods.cjs TOOLING INPUT.glb CONFIG.json NEW.glb`.
Repeat chains for body, clothing and hair parts. Mesh names must be unique. Each
alternative must use the same skin identity and exact set of named morph channels.
Targets must be leaf nodes; they are detached from scene traversal while retained
for importer skin resolution. The tool does not generate lower-detail geometry,
textures or missing morphs. Input should be decoded standard glTF/GLB; compressed
extensions need decoding first. Existing VIVID manifest points at resulting model.
