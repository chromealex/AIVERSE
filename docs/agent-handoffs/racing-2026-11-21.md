## Stage 1b — no genre split: races are a shared capability (2026-11-21)

Owner rule (now the first section of AGENTS.md, "NO GENRE SPLIT — EVER"): features are never gated by genre or
module. Stage 1 violated it (`fps.mode "race"`, `fps.race`, FPS-only HUD); this stage removes that.

- Data, one format for every project: rules `"race"` (`readRaceRules`) and map `"race"` (`readRaceTrack`: checkpoints
  with `x`/`z`/`yaw`/`width`, optional `grid`, racing `line`, in the map's own units) —
  `libraries/include/aiverselib/genre/RaceSessionData.h`. `RaceView` + `raceView()` moved into `RaceSession.h`
  (io in `VehiclePersistence.h`). Docs: `docs/races.md` (new, the reference).
- Removed: `fps.mode "race"`, `fps.race`, `fps::RaceRules`, `fps::RaceView`, `apps/fps/RaceHud.h`. A map `"race"` makes
  the FPS host race (`modules/fps/FpsRace.cpp`, adapter only); save version 10 only on maps with a race.
- Second host: the grid-map driving host (`engine/game/Driving.cpp` + `RtsRace.h`): racer i = i-th car = player
  i + 1 (hero seated, doors held), `"bot"` players or players without a hero race with the bot; the race decides the
  match (`winnerTeam`); `DrivingRaceState` hashed and saved only on maps with a race. `Driving::seat` factored out
  of `enter`. Crash damage on racers follows rules `race.crashDamage`.
- Shared presentation: `engine/ui/RaceHud.h` (HUD) and `engine/render/ChaseCamera.h`; used by the FPS client and by
  the grid-map client (`apps/client/GameClient.cpp`). Lang keys renamed `fps.race.*` -> `race.*`.
- Template `templates/racing` + `racegen.py` write the shared blocks. Skill `aiverse-racing` rewritten host-neutral.

## Stage 1c — demo: race on a spline road with Kenney trucks (2026-11-21)

- `templates/road_race` (Road Circuit): grid map 72x52 cells, the circuit is a `roadNetwork` loop of 14 cubic Bezier
  edges (Catmull-Rom through hand-placed points; road type `circuit`: two 4.5 m lanes centred on the spline, grass

  cells) on all four `wheel-*` nodes; handling from the wheel positions of the model.
