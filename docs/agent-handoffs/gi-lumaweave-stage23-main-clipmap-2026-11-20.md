## Behavior, backend ownership and limitations

- **GLES3/OpenGL/Vulkan:** the portable CPU `GiDynamicRuntime` ray tracer produces a bounded, moving L1 probe atlas in **RGBA32F**. The renderer checks format/device/count, binds `tex13` + std140 U6 into current-view PBR model shaders, and samples the tetrahedral SH-like coefficients in linear diffuse. This is NOT GPU compute bounced GI on Vulkan/GLES; their normal Direct remains Vulkan compute opt-in or raster. A device that cannot sample RGBA32F or a mobile model tier set to Low rejects the overlay instead of claiming it was drawn.
- **Metal:** `GiGpuCascadeRuntime` uses GPU-written, completion-validated RGBA16F fine/medium/distant atlases with a per-physical-probe R8 validity mask. The renderer supports 1..3 optional cascades, dual-cascade smooth boundary blending and a third coarse fallback through `GiCascadeShaders.h`. GPU dispatch/probe publication remains owned by the pre-existing GI runtime; this stage adds only the renderer presentation binding. The experimental Metal PBR GPU ICB path is bypassed only for GI views due to a real fragment buffer8 conflict. Non-GI model ICB still works as before.
- **MAIN model engine stays intact:** actual PRISMA rigid/skinned/instanced/morphed motion and reactive passes, MAIN MDI/ICB profiler/retirement, material palette, shader graph, NEREID/PHYSIS effects, input/ECS, baked GI/lightmap, standalone postprocess all untouched except specifically described optional shader branches and safe view resets. Shader graph materials with owned textures at slot13+ currently do **NOT** receive extra L1 at the same time; unlit/Low-tier models likewise skip it. This is explicit unsupported coverage, not silent override. Custom terrain/sprite/water shaders have not been given this new L1 path; the current implementation applies to MAIN PBR models. Full scene GI quality therefore needs backend capture tests.
- **Source ownership:** `LumaWeaveNativeDriver::frame` calls `beginScene`, clears any prior view state, publishes CPU/GPU GI probes before rendering and binds only accepted current source+geometry revisions, with a scoped `clearDynamicGiOverlay` on view return. Never keep borrowed `GiDynamicProbeTexture` or R8 mask pointers beyond owner lifetime. Metal GPU jobs already require real completed GPU fence before overwriting a shared atlas.
- **Direct/bounced/baked energy:** a GI overlay contributes diffuse **bounced indirect** only. The old dynamic-grid indirect is suppressed in the shader variant; legacy DIRECT point/sun light and existing baked/probe GI remain distinct. A host must avoid including the same static baked source in moving bounce data twice, a scene content ownership rule.
- No default automatic GI or Vulkan compute on GLES was introduced. No source API or serialization changes to gameplay/ECS or genre modules.
