## API and safe frame ordering

1. Host owns and begins `gfx::Device::beginFrame`, then `LumaWeaveNativeDriver::frame` gathers immutable source/BVH snapshots and calls `renderer_.beginScene`. An opt-in Vulkan view sets `enableVulkanDirect=true`, `vulkanHistoryKey` nonzero, `vulkanHistoryEpoch` and `vulkanDynamicGeometryVisible=true` for moving opaque meshes. The existing `vulkanObjectMotion` manual field may be left empty.
2. `Renderer3D::render(...,&vulkanPost)` draws real opaque material/normal depth receiver passes and HDR color/depth. Main's producer automatically calls the PostProcess object motion hooks in its render-end phase, or the older isolated renderer calls a **one-time installed** `ObjectMotionProducer` callback after ending the scene color pass.
3. Motion producer can request actual scene depth and previous camera VP/epoch, draws truthful skinned/rigid/deformed velocity into a per-view RGBA16F target, ends that render pass and publishes `MotionTextureInput::declared(source,width,height,RGBA16F)`. Main producer already has a per-view previous-pose cache. No invented camera-only object motion is supplied by LumaWeave.
4. Luma PostProcess verifies metadata, GPU frame and view context, makes an **independent frame-retired exact FP16 copy** into the sixth receiver-slot image. The source remains owned by the producer and must survive until the GPU copy has completed; the new image is owned by LumaWeave for its own in-flight GPU uses. The owner then reads only this private copy via existing Stage19 seven-sampled-input denoiser, preserving signed object UV and B-valid semantics. Missing typed data or failed copy means current spatial lighting, no stale history.
5. At `PostProcess::resolve`, the latest current VP is saved per stable view key+epoch for the next renderer producer. Hard cuts and actual route disable invalidate it; transient GPU-busy fallback can explicitly preserve existing history. Everything remains presentation-only, independent of ECS/animation/network save state.
6. Vulkan Direct is off by default; GLES3/WebGL2 remain raster direct + CPU L1 GI. Sun/baked/GI remain separately owned and are not counted as LumaWeave DIRECT.
