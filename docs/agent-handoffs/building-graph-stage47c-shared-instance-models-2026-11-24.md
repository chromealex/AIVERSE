# Stage 47C — shared building templates and render instance publication

Continues 1cf3e409. BuildingInstances.h normalizes generation to local origin/yaw, shares immutable CPU leases and uses a full encoded cache key with caller-owned content namespace, style revision and material revision. Independent placements transform exact static boxes, gates and anchors with the existing quarter-turn/minimum-corner convention; gameplay state remains with existing owners. BuildingInstanceRenderer.h is a render-thread adapter: validates stable IDs, deduplicates model keys, prepares/uploads each missing shell once via existing ModelResourceCache, stages partial uploads behind its retirement queue, acquires a frame read scope and submits one ModelDraw per instance to existing Renderer3D instancing and authored LOD selection. Caller retains frame through rendering, supplies globally unique persistent IDs and advances revisions whenever style or resolved material content changes; cache trimming/retirement remains existing host responsibility. No custom instancing shader or draw count guarantee. No automatic BuildingWorldRuntime integration, separate dynamic leaf/lift/damage/light submission, atlas or per-room visibility. Shared models immutable; static shell only. Source CPU regression authored for key/revision, transforms and lease reuse; no GPU test or build run. No main merge.
