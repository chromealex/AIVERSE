Successful checked clear immediately attempts to return to min(256, logical limit). A failed optional shrink does not invalidate a successful clear; old empty allocation remains usable. Estimates only schedule checks, never authorize retirement. Proof prevents idle compute dispatches; next birth resumes execution and can regrow. Retry after cooldown. Fresh empty buffers contain a valid free stack/counters; unused state is initialized by birth before access. Existing pipeline, logical limit, owners, and fixed-capacity paths unchanged.
