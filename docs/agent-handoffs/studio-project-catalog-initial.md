# HTML5 Studio Project catalog

The old ProjectWindow browsed the maps directory and four rules groups. The previous HTML panel used only the manifest map list. The port extends studio.project and the existing map-open path with local maps, adds a project-scoped rule read/write method using the existing rules_set owner, and preserves optimistic per-item edits. The same HTML page fits the side dock and center workspace.

Mac desktop checks exercised filtering, opening an unlisted file, manual refresh, resource create/rename, persistence across restart, duplicate rejection and the Rules shortcut. Three screenshots are in docs/evidence/studio-project-catalog. Windows and the overall migration gates remain open.
