# Desktop capture workload and publication handoff

Implementation commit `965f7c674` adds explicit backend selection to the lightweight capture command and a reproducible indexed 16,384-triangle torus-knot workload. The Windows acceptance system ran native MSVC Release CPU, D3D9 HAL and D3D11 WARP captures. The x86_64 macOS CPU capture on Apple Silicon under Rosetta produced the same PNG digest as Windows CPU. Foreground pixels ranged from 43,368 to 43,370 at 512 × 512. The median of five fresh-process captures after one warm-up was 102.15 ms for CPU, 96.94 ms for D3D9 HAL and 94.50 ms for D3D11 WARP on the Windows runner. These include startup, OBJ parsing, device and shader setup, drawing, readback and PNG writing. No isolated GPU timers or physical GPU comparisons were performed. Full samples, hashes, configuration and method: docs/evidence/render-backend-thumbnail-performance.json. [Workload run and frames](https://github.com/chromealex/AIVERSE/actions/runs/45609159189).

Commit `d99049d1dadb8a4116c4ecd447d54c02562bb43c` adds original engine frames and the bilingual gallery entry docs/devlog/entries/2026-11-25-render-backend-thumbnails.json. The site check passed with 61 entries. A local two-language build produced 152 pages and 138 media files. The English and Russian devblog-render pages each contained all three native PNGs with bytes identical to the committed captures. The entry explains the desktop CLI and Windows API limits in browsers. The MAIN integrator publishes the prepared site after integration.

Final Mac verification built the CPU consumer and passed render_cpu_device and render_cpu_textured_model. On the same content commit the hosted Windows Server 2022 x64 runner rebuilt the consumer, passed the six native WARP/HAL, RHI and window/resize tests, and ran five model captures for each backend. [Final Windows CI](https://github.com/chromealex/AIVERSE/actions/runs/45609748449). Acceptance remains scoped to RGBA8 indexed model previews, sampled textures and HWND resize. The full game shader suite and physical D3D11 hardware throughput were outside these captures.
