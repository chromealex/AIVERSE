# Stage 43 — optional unique building UV atlas

Continues acff5c4a, same integration branch. CPU deterministic triangle chart packing, four shared PBR maps, periodic bilinear source sampling, four-pixel replicated gutters, per-material factors preserved and texture transforms baked (positive UV scale and offset only). Native preview and GLB share the baker. Studio selectable layout, candidate identity and saved recipe/regeneration roundtrip. Unique mode does not modify physical geometry or triangle count; vertex duplication expected. One atlas page up to 2048, maximum 50000 triangles and density fallback 32/16/8/4, per-chart max 64 interior pixels. Explicit failure when packing or inputs unsupported. Imported GUIDs, UV rotation, negative/zero scale and nonprocedural materials unsupported in unique mode; tiled default unchanged. Triangle chart approach may reduce detail, mip bleed remains possible at coarse mip levels, no lightmap UV or draw-call merging, no atlas export as independent asset yet. Geometry inspection does not bake/validate atlas; preview/export do. Source regression added; no compile/CTest/native GPU/visual verification. No main merge.
