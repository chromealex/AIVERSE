EvolvePlanetNaturalFalls.h reuses existing rooted authority, ecological death records, planetary deadwood ledger and durable root-fall outbox. Optional planetForest.naturalFallPermille (0 disabled, 1..1000) latches standing dead trees/shrubs at the configured nonzero remaining biomass threshold; already fallen or fully spent wood does not spawn new consequences. This is a threshold policy, not a progressive biomechanical root-strength solver. Actual PHYSIS gravity supplies a tangential direction when available; existing RootSupportRegistry stable azimuth handles symmetric/zero gravity. The legacy sourceSoilRevision receipt field carries the new rooted authority revision for natural mortality (no terrain mutation). Root state and event publication are atomic. Existing erosion fall and natural fall share the same latch.

Optional per-species naturalFallBody (radiusCm, halfHeightCm, density, frictionPermille) supplies an explicit native capsule recipe. The pipeline stages the durable shape, initial lean and acknowledgement in its existing World transaction. Missing recipe leaves a pending event for the custom owner. No extra biomass, gravity integration, physics solver, or second plant store. Existing PlanetProcessHost/PlanetConsequencePublisher can project durable records to actual Box3D and apply PHYSIS. The default GameCore host does not automatically instantiate that physical host; real falling motion requires a configured native physics scene. Capsule dimensions and lean are authored approximations, not mesh-derived collision; the old static source must be registered with the existing native source publisher to be retired. No guarantee of tipping under zero gravity.
