Date: 2026-11-24. Base 87f8d76a19ecf6ab8b51f7336ff9d9481cf59bfb. Branch feature/world-processes-stage31-bidirectional-handles.

Add optional sampler callback to existing NEREID sphere sampling stage, without changing its default standalone behavior. GameCore heightfield planetary seas now query current immutable Surface on each sample: isolate water bodies by canonical centre, clip local floor to radial terrain, reject buried probes and dry land above sea, preserve existing priority/waves/current and use same buoyancy/interaction outputs. No new water state, no duplicate sampling system. Non-heightfield maps retain legacy shell policy. Save/rollback reads actual restored terrain on next scheduled sample.

PlanetTerrainWater.h also supplies read-only shoreline ground/wetness/current forcing to existing NEREID erosion policy, projecting current onto east/south tangent axes (no mistaken global XZ velocity). This does NOT run erodeShore, change suspended sediment, alter sea volume/level, solve spherical flood routing or commit erosion. NEREID's current sediment units assume equal-area samples; Stage129 geometry uses cm^3 triangulated volume. Need a conservative conversion and owner transaction before enabling erosion, plus prescribed-level vs finite-volume water design. PHYSIS wave input is explicit owner parameter; no gravity or flood solver duplicated. Existing sphere buoyancy remains its radial policy, not automatic PHYSIS gravity coupling.
