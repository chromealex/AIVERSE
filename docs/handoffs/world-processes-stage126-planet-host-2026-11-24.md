## Owner contract
Call prepare only after authoritative Simulation tick, terrain and durable fracture consequences are committed; supply completed tick (Simulation::tick()-1), terrain revision, nonzero epoch, canonical shared Surface, stable placement/residency. Scene is exclusively stepped by this host for this interval; other authoritative owners must coordinate within that schedule, not advance it independently. All host calls serialized, including GPU and physics operations; callers enforce native owner threads and GPU lifetime fences. Root climate is a synchronous read-only owner query. Before physics, owner removes replaced support colliders, supplies durable debris records and retires obsolete projections; initial character proxies must be correctly oriented. stepPhysics updates owner-provided character state and proxies, applies forces/pushes once, steps Scene and copies quantized contacts. recordContacts callback persists next-tick input in existing replay/network channel, deduplicates by epoch/tick; before next MORPH tick call enqueueMorphContactInputs on authoritative ECS using recorded inputs, not float resampling. publishRender and update/attach model streams use same prepared snapshot. Do not draw stale frames after fault. Reset requires owner reconciliation/restoration of physical state (including clearing partial forces), not just clearing projection cache. Explicitly shutdown before Scene/Device/assets are destroyed. This is an opt-in composition, not a global Simulation system.
