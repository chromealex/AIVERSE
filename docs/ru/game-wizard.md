# Мастер «Сделать игру»

Одно окно (хаб проектов → **Сделать игру** или **Проект → Сделать игру…**) или один вызов MCP (`game_make`) создают
целый игровой проект со своим `.rtsproj`: игру на шаблоне, подобранном по идее, арт / модели / музыку / звуки
пользователя, карту жёсткого обучения, мягкие подсказки в матчах, сгенерированные уровни, мету (меню, улучшения,
магазин, награда дня, профиль, настройки, результат), покупки и рекламу по запросу, языки, брендинг и проверку ботами.
Всё, что он пишет, — обычные данные игры, которые потом можно править.

Код: `apps/editor/core/GameWizard*.cpp` (без UI), `apps/editor/core/WizardOps.cpp` (MCP), `apps/editor/EditorGameWizard.cpp`
(страница хаба). Набор для игры, который копируется в каждую игру: `templates/_wizard/` (Lua + RmlUi, см. его README).

## Ответы (`WizardSpec`, всё необязательно)

| Группа | Ключи |
|---|---|
| Контент | `artDir` (папка: png/jpg/tga, glb/gltf/obj/fbx, wav/ogg/mp3/flac, ttf/otf, md/txt), `artUrl` (файл или .zip / .tar.gz; скачивается системным curl в `~/.aiverse/wizard/<время>`) |
| Идея | `idea` (на любом языке; .md/.txt из папки тоже читаются), `genre` (id шаблона или `auto`), `features` (economy base army garrison lanes waves territory heroes spells survival planets 2d casual portrait scifi modern) |
| Проект | `title`, `location`, `studio` (bundle id `com.<studio>.<slug>`), `version`, `orientation`, `languages`, `platforms`, `seed` |
| Обучение | `tutorial` (`both` / `hard` / `soft` / `none`), `tutorialForced`, `tutorialSkippable`, `tutorialDim`, `hints` |
| Уровни | `levels` (0..40), `mapPreset` (`auto`, `none` = копии базовой карты, или пресет генератора), `mapSize`, `bossEvery`, `difficultyCurve`, `startResourcesPercent`, `keepTemplateMaps`, `verifyLevels` |
| Мета | `metaIdea` (свободный текст: что должно быть в мете; уходит в задание агенту), `currencies` (soft, hard), `upgrades`, `shop`, `daily`, `profileScreen`, `xpPerLevel` |
| Деньги | `ads`, `interstitialEvery`, `purchases`, `stores` |
| Внешний вид | `brandingFromArt`, `paletteFromArt` |

`game_make_options` перечисляет варианты, `game_make_plan` показывает, что будет создано (без файлов). Одинаковые ответы
+ seed = одинаковая игра.

## Как он решает

- **Шаблон**: слова идеи сравниваются с ключевыми словами каждого шаблона (основы слов, ru / en), нужные возможности —
  с его механиками, ориентация — с его экраном; при равенстве решает seed. Ничего не задано — один из сбалансированных
  шаблонов.
- **Контент**: модели и 2D-спрайты достаются типам, чей id / имя (ru / en) есть в имени файла; остальное копируется и
  перечисляется в `WIZARD.md`. Ключевой арт (по имени и размеру) становится заставкой, фоном меню и акцентным цветом
  интерфейса; самая квадратная картинка (или «icon» / «logo») — иконкой 1024. Музыка по имени — в `menu` / `match` /
  `battle` / `victory` / `defeat`, короткие звуки — на события (`click`, `select`, `move`, `died`, `underAttack`, ...).
  Первый шрифт TrueType становится `fonts/title.ttf`.
- **Жёсткое обучение** (`maps/wiz_tutorial.json` + `scripts/wizard/tutorial_steps.lua`) пишется по правилам игры:
  - *экономика* (рабочие, верфи сайдбара, разворачиваемые MCV, строители TA): развернуть, добывать, warp-поле / лимит
    при необходимости, цепочка требований для производителя вроде казармы, обучить двух юнитов, снести вражеское здание,
    которое не отстреливается;
  - *гарнизоны* (Mushroom Wars, State.io): отправить войска в нейтральное здание, взять ещё два, взять вражеское;
  - *автостройка* (лайн-баттлеры): дважды нажать «Строить», улучшить, удержать;
  - *общий случай*: передвинуть армию, атаковать.
  Проходят только команды текущего шага (`before_command`), враг ждёт (его юниты всё равно обороняются), панель и стрелку
  рисует view-скрипт, ресурсы шага пополняются, чтобы нельзя было застрять. Не для дорожных экономик в стиле Knights and
  Merchants (там общий вариант).
- **Мягкое обучение**: одноразовые подсказки (камера, простаивающие рабочие, не хватает ресурсов, лимит, армия,
  гарнизоны, нас атакуют) из `scripts/wizard/hints_config.lua`; увиденные подсказки запоминаются в профиле, в настройках
  их можно выключить.
- **Уровни**: `maps/wiz_level_N.json` = базовая карта + `generate` (пресет шаблона, свой seed на уровень, базовая карта
  как образец); сложность 0..2 по кривой, каждый N-й — босс; награды, награды за первую победу и время для звёзд — в
  `ui/wizard.json`.
- **Мета**: `ui/wizard.json` (настройки), `ui/profile.json`, `ui/shop.json`, `ui/screens.json` (`start: home`,
  `afterMatch: result`), экраны из набора. Улучшения попадают в матч как `initialVars` `wiz_up_<id>`, а
  `scripts/wizard/meta_bonus.lua` превращает их в баффы / стартовые ресурсы.
- **Деньги**: `plugins` / `store` / `ads` в `game.json` по платформам (демо-блоки рекламы Яндекса и заглушки для
  десктопа: замените id).

## Шаг агента: описанная игра один в один

Шаблон — отправная точка, а не игра. Если `agent` включён (по умолчанию), мастер пишет в проект `WIZARD_TASK.md` —
описание / GDD дословно и правила, как сохранить согласованность частей мастера (шаги обучения, подсказки, настройки меты,
файлы языков), — и передаёт его подключённому AI-агенту. Агент перестраивает проект через MCP-инструменты редактора
(вживую в редакторе): типы, характеристики, фракции, механики (правила или Lua), карты, условия победы, тексты; затем
проверяет `rules_lint`, `map_validate`, `match_run` и пишет «## Агент: что сделано» в WIZARD.md.

- Подключение: мастер показывает ту же панель «подключить AI-агента», что и окно Agent (`EditorMcpConnect.*`,
  `core/McpInstall.h`): один клик записывает aiversemcp в конфигурацию клиента, и это одно подключение служит обоим.
- Запуск из редактора (`core/WizardAgent.*`, через login shell пользователя, чтобы CLI нашёлся):
  Claude Code `claude -p --output-format stream-json --allowedTools mcp__aiverse` и Codex CLI `codex exec --full-auto`,
  задание — на stdin, рабочая папка — папка проекта. CLI ищется в PATH, обычных папках установки, shell пользователя и
  внутри настольных приложений (Claude Code в `~/Library/Application Support/Claude/claude-code/<version>/…/claude.app`,
  Codex в `ChatGPT.app/Contents/Resources/codex-cli`). Ход работы — в ленте активности (окно Agent), строке состояния и на
  странице мастера (кнопка «Стоп»); полный журнал — в `logs/wizard-agent-<время>.log`.
- Cursor, Windsurf, Claude Desktop: «Скопировать задание агенту» кладёт задание в буфер обмена, чтобы вставить его в клиент.
- Никакого API-ключа в редакторе: агент работает в собственном клиенте и под аккаунтом пользователя.
- Диктовка: «Наговорить» под полем идеи (страница «Идея») и под полем идей меты (страница «Мета») — распознавание речи
  macOS (`apps/editor/EditorSpeech_mac.mm`: Speech + AVFoundation, локаль — первый язык игры; система один раз спрашивает
  доступ к микрофону и распознаванию). Текст добавляется в поле. На других платформах кнопка неактивна.
- `ai` в спецификации (тексты по языкам: слоган, вступление, типы, ресурсы, валюты, улучшения, уровни) позволяет агенту,
  который сам вызывает `game_make`, передать названия и тексты игры.

Обучение в окне Game редактора: у редактора нет игрового интерфейса для панели шагов, поэтому view-скрипт шлёт
`wiz_tut_off`, и карта обучения играется там как обычный матч. Панель, стрелка и фильтр команд работают в игровом
клиенте (AiverseGame, сборки). Редактор открывает первый уровень, а не обучение.

## Проверка

С `verifyLevels` мастер сам проходит обучение (`initialVars {wiz_tutorial_auto: 1}`: приказ `auto` каждого шага проходит
через тот же фильтр, что и у игрока) и выборку уровней с ботами и сообщает об ошибках загрузки, ошибках скриптов и
незавершённом обучении. Проверено на каждом шаблоне: всё завершается, кроме ambersands (стройка только на скалах), planets и
underlord (передвижение / копание по особому рельефу) — мастер говорит об этом в предупреждениях.

Тесты: `game_wizard_plan_picks_a_template_by_the_idea`, `game_wizard_makes_a_playable_project`,
`script_command_card_false_hides_the_button`.

## Изменение движка

Скриптовые команды принимают `"card": false` (без кнопки / горячей клавиши; их шлют view-скрипты, HUD-документы, MCP) —
это «Далее» / «Пропустить» обучения (`modules/rts/RtsScriptCommands.cpp`, командные карточки клиента и редактора).
