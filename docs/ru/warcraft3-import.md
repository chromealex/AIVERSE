# Импорт карт Warcraft III

Команда принимает карту `.w3m`, `.w3x` или каталог с распакованными файлами. Для чтения архивов MPQ установите StormLib. Укажите существующий проект AIVERSE с `game.json` и `rules.json`.

```bash
python3 tools/importers/warcraft3/cli.py --source MyMap.w3x --project /path/to/project --game-data /path/to/extracted-game-data
```

В `--game-data` передайте распакованные данные игры, если карте нужны стандартные модели. Для моделей внутри самой карты этот параметр можно опустить.

## Результат

Импортёр регистрирует карту с рельефом в проекте, добавляет найденные типы объектов в правила и записывает юнитов и декорации с моделями в `map.entities`. Объекты получают координаты на плоскости карты. Исходные высота, поворот, масштаб и владелец сохраняются в метаданных Warcraft III. Размещения, для которых модель не нашлась, перечислены в отчёте.

Карту можно открыть в Studio. Игровая логика Warcraft III, триггеры, вода и проходимость требуют отдельного переноса.
