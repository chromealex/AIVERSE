# Triplanar stone

Open this project in Studio or build for Web and start the gallery map. Rotate the camera using Front and Side and inspect the wall of the central bore. Zoom out for a view of the whole model. The bind-pose GLB is a Modeling volume CSG export with a 0.5-metre bore. The saved wildcard material applies an ordinary world-space Shader Graph, two original periodic stone textures and a repeat length of 0.46 metres. Every view samples the same stone material.
