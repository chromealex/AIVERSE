# Projectile segments

Choose one of four scenes (or open index.html?map=0 through map=3): straight, arc, ricochet and timed split. Select the launcher, then right-click a low or tall target to fire. Escape opens Pause; Restart resets the scene and Main menu chooses another scene. Rotate/zoom the camera to inspect the imported green diamond and trail.

All scenes use ordinary weapon flight data, the shared projectile presentation sample and the existing trail binding. No demo-specific engine code. Source presets derive from the native Metal acceptance fixtures retained under docs/evidence/issues-projectile-metal-20261127. Browser acceptance and publication pending.
