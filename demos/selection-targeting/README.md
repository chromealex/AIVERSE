# Selection and targeting range

Start the Training range map. Click the standalone oak or drag a selection box around it and the scout. The oak stays in the world while the client skips it. Use **Select oaks** (E) to switch the two trees to a selectable type. Select an oak and use **Pass through oaks** (D) to restore the initial behavior and clear its selection.

The scout automatically fires on the target in the earlier map row. To compare the same map with distance-based acquisition, open the project in Studio, set **Logic → Rules → Auto-target order** to **Nearest**, and restart the match. The second target is closer to the scout. In the deployed Web game, append `?map=0` to start on the range.
