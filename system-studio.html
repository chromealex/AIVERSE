Engine systems / Studio editor

Studio editor

An editor for a person and an agent

A Unity-style editor with a scene, an inspector and play testing. An agent edits the same project, and every action can be undone.

System docsDevelopment diary · 8

What is inside

Windows

Scene, hierarchy, inspector, terrain, effects, lighting, UI; free docking.

Game and device simulator

Run a match right in the editor on phone and tablet screens.

Agent panel

Claude Code works on the open project, every edit is an undo step.

Make a game wizard

An idea and a folder of art become a project with levels, a tutorial and meta.

Project C++ modules

The editor builds a version with the project's modules and restarts into it.

What it lets you do

  • Make and test a game without leaving the editor.
  • Work together with an agent on one project.
  • Check layouts on the screens of different phones.
