Системы движка / Интерфейс игры

Интерфейс игры

Меню и HUD на HTML и CSS

Меню, HUD, миникарта и пауза — документы RmlUi в разметке и стилях, а не код.

Статья о разработке

Что входит

HTML и CSS

Разметка .rml и стили .rcss; игра заменяет любой файл своим.

Скины

Свои цвета, рамки и шрифты на игру; портретная раскладка для телефонов.

Масштаб

Размеры в dp, крупные кнопки на сенсорных экранах.

Языки

Тексты ключами, смена языка перезагружает документы.

Экранная клавиатура

Своя клавиатура с раскладками для полей ввода на телефонах.

Что позволяет делать

  • Сменить весь интерфейс игры одним файлом стилей.
  • Перевести игру на любой язык без правки разметки.
  • Дать агенту верстать экраны как веб-страницы.
