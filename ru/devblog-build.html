    Каталог пакетов: контент скачивается отдельно от движка

    Библиотеки PBR-материалов ландшафта и растительности и их исходники переехали из движка в каталог пакетов. Проект ставит только то, что ему нужно, одной командой; на сайте появилась страница «Каталог».

    Каталог — отдельный репозиторий AIVERSE-PACKAGES с разделами: шаблоны, материалы, текстуры, модели, звук, эффекты, интерфейс, скрипты, плагины, инструменты. У каждого пакета есть описание, превью, лицензия и минимальная версия движка.

    Команда `aiverse_pkg.py add terrain-pbr --project <проект>` скачивает пакет, проверяет его хеш, кладёт файлы в проект и добавляет материалы в его библиотеку. Версия и хеши файлов записываются в `aiverse.lock`, так что клон проекта восстанавливается командой `install`. Скачанный пакет хранится на компьютере один раз для всех проектов.

    Навыки движка указывают, какие пакеты им нужны, и агент ставит их сам.

    Новые пакеты добавляются через pull request в каталог. После принятия пакет сам появляется в движке и на странице «Каталог»: превью, описание, версия движка, кнопка скачивания и команда установки.

    Проверено
    Четыре пакета опубликованы в каталоге и скачаны по сети на Linux; текстуры из них побайтно совпадают с прежними файлами движка, проверки карт материалов проходят. Страница «Каталог» открыта в Chrome на компьютере и телефоне и показывает пакеты из каталога.
    Ограничения
    Окна каталога в Studio и команд MCP пока нет: поиск и установка — из командной строки. Сборка редактора с изменённым пустым проектом на macOS не проверялась.

    Просмотрщик каталога: формы, LOD и STRATA, анимированный знак загрузки

    3D-просмотр пакетов каталога показывает материалы на сфере, кубе, цилиндре или плоскости с текстурами в исходном размере, а модели — по уровням LOD или через STRATA. Все загрузки на сайте, в Studio и веб-сборках теперь показывают анимированный знак AIVERSE.

    Над окном просмотра — переключатель формы для материалов. Плотность текстуры одинакова на всех формах, на сфере и цилиндре число повторов целое, поэтому шва больше нет. Текстуры приходят такими, какими их опубликовал автор пакета: тонкие края листвы с вырезом по альфе больше не превращаются в кляксы. Панель слева показывает каждую карту — цвет, нормали, ORM, AO — с размером в пикселях и весом файла.

    Для моделей: Авто LOD (подсвечен уровень, который рендер выбрал на этом расстоянии), любой уровень вручную или STRATA — кластеры строятся из модели при первом выборе, кнопка «Кластеры» их раскрашивает. «Сетка» показывает рёбра текущего уровня. Панель пишет треугольники по уровням, сгенерировал ли LOD движок, число кластеров и время сборки STRATA.

    Знак загрузки — та же сборка лопастей и ромба, что в заставке движка: на сайте (каталог, сборки на странице релизов), в просмотрщике, в Studio вместо крутилок и в веб-сборках игр без своей заставки.

    Проверено
    Кадры сняты в настольной сборке просмотрщика (Linux, OpenGL) на пакетах terrain-pbr и vegetation-pbr и на тестовом камне в 20 тыс. треугольников; знак загрузки снят на собранном сайте в Chrome.
    Ограничения
    Веб-версия просмотрщика собирается в каталоге и проверяется после выкладки. В каталоге пока нет пакетов с моделями, поэтому LOD и STRATA на сайте появятся с первым таким пакетом. STRATA собирается при первом выборе, на крупной модели это заметная пауза.

    В работеfeature/aiv20261122_template_packages

    Шаблоны проектов из каталога пакетов

    Все 36 примеров игр движка теперь — официальные пакеты-шаблоны в каталоге AIVERSE-PACKAGES. Стартовый экран Studio показывает их первыми, а кнопка «More templates» ищет по всем шаблонам каталога, включая шаблоны других авторов.

    Шаблон теперь может расти: свои текстуры, модели и код живут в его пакете, а не в репозитории движка. Каталог отмечает официальные пакеты флагом official — его ставят только авторы AIVERSE.

    Проект из пакета-шаблона скачивается, проверяется по хэшу и распаковывается в выбранную папку, затем ставятся пакеты, которые указаны в его game.json. Стартовый экран открывается сразу из кэша и обновляет список в фоне. Агенты делают то же через MCP: create_project с шаблоном pkg:<пакет>.

    У каждого шаблона в каталоге есть превью — настоящий кадр движка, снятый с этого шаблона.

    Проверено
    Проект «Mushroom Clash» создан из пакета mushrooms через MCP create_project и запущен в клиенте (Linux, OpenGL): первый кадр. Остальные кадры — превью шаблонов, снятые клиентом движка для каталога.
    Ограничения
    Новый стартовый экран Studio собран и проверен типами, но не запускался в нативном Studio на macOS. Папка templates/ пока остаётся в движке для работы без сети и для тестов.

    Каталог: камни и деревья TerraWeave, пакеты с зависимостями, переводы

    В каталоге первые наборы моделей: 12 камней и 10 пород деревьев TerraWeave, по три LOD. Пакет может брать текстуры другого пакета вместо копий. Тексты каталога — английские с переводами вроде title-ru; на странице каталога есть инструкция, как добавить свой пакет.

    `terraweave-rocks` и `terraweave-trees` сделаны инструментами движка aiverse_terraweave_rocks и aiverse_terraweave_vegetation. Модели ссылаются на текстуры пакетов terrain-pbr и vegetation-pbr, поэтому набор деревьев весит 17 МБ вместо 52. `aiverse_pkg.py add` сначала ставит зависимости, 3D-просмотр на сайте берёт текстуры из них же.

    Индекс каталога стал коротким: в корне только разделы и путь к папке каждого пакета, описание лежит в его aiverse.package.json, опубликованные версии и хеши — в versions.json рядом. Тексты без суффикса — английские, переводы — title-ru, summary-zh-CN и т. д.; README каталога есть на девяти языках.

    На странице «Каталог» — пять шагов, как предложить пакет, и ссылка на подробную инструкцию в документации.

    Проверено
    Модели с текстурами из пакетов-зависимостей сняты в настольной сборке просмотрщика (Linux, OpenGL), включая STRATA на дубе; установка с зависимостями проверена тестом aiverse_pkg; страница каталога с новым индексом проверена в Chrome на локальной копии каталога.
    Ограничения
    Деревья — для ручной расстановки; лес, который движок сам растит и расставляет, по-прежнему строит TerraWeave. Переводы описаний пакетов пока только на русский.

    Клиентская сборка берёт только нужные модули движка

    В game.json можно выбрать, какие необязательные части движка попадут в собранную игру, или поручить это автоматике: "engineModules": ["auto"].

    Раньше каждая собранная игра несла весь движок: частицы, Spine, геймпады, загрузчики FBX и старых форматов моделей, клиент городского сервера, симуляции трафика и генерации карт. Теперь их можно отключить списком packaging.engineModules — общим или для отдельной платформы.

    Режим "auto" сам смотрит в проект: Spine и геймпад по game.json, частицы по файлам эффектов, загрузчики по исходным моделям, симуляции по правилам и картам. Если игра использует то, что исключено, сборщик откажется собирать с понятной ошибкой; без поля всё собирается как раньше.

    На пробной сборке клиента для macOS исполняемый файл стал меньше примерно на 7% только за счёт того, что линкуется лишь используемый код. Каждый отключённый модуль убирает ещё от примерно сотни килобайт (геймпад) до пары мегабайт (частицы, старые загрузчики моделей).

    Проверено
    Сборщик проверяет выбор модулей для Web, Windows и macOS; размеры измерены на клиенте для macOS.
    Ограничения
    Размер и запуск HTML5-сборки ещё не измерены: на машине сборки не было Emscripten. Android, iOS, Windows и Linux тоже ещё не собирались с выключенными модулями.
