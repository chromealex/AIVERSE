Shader Graph

Материалы и эффекты из узлов

Графы для материалов, постэффектов и частиц. Один граф даёт шейдеры GLSL и Metal, превью идёт на настоящем рендере.

Статья о разработке

Что входит

Три вида графов

Материал, постэффект и частицы; граф встраивается в материал, game.json или эффект.

103 операции

Математика, шум, текстуры, параметры, вершинные выходы.

Безопасность

Проект не может подсунуть свой код шейдера: только проверенные узлы.

Превью

Освещённая сфера, картинка с постэффектом или цикл частиц прямо на GPU.

Агенты

Граф правится через MCP, есть готовая библиотека стартовых материалов.

Texture Graph GPU — Stage 38A

Добавлен opt-in режим генерации текстур для материала без чтения пикселей на CPU. Изолированный тест бюджета пройден; сборка и GPU-проверка ещё не выполнены.

Texture Graph GPU — Stage 38B

Вынесен общий нативный GPU owner и типизированный API генерации материалов; Studio использует тот же владелец. Интегрированная сборка и аппаратная проверка ожидаются.

Texture Graph GPU — Stage 38C

Добавлен инкрементальный GPU DAG: неизменённые узлы переиспользуют данные постоянных слотов. Изолированный тест пройден, аппаратная проверка ожидается.

Texture Graph GPU — Stage 38D

Добавлена ограниченная асинхронная очередь GPU-запросов с приоритетами, отменой и явной выдачей результата. Изолированный тест пройден; интеграционная проверка ожидается.

Texture Graph GPU — Stage 38E (частично)

Добавлен нативный механизм освобождения текстур с сохранением индексов и диагностикой. Автоматический сбор в игровом хосте и тестирование ещё предстоят.

Texture Graph GPU — Stage 38F

Нативный игровой клиент подключён к общему GPU owner и применению материалов на границе кадра. Изолированный тест прошёл; интеграционная проверка ожидается.

Texture Graph GPU — Stage 38G (частично)

Подключены GPU scopes с идентификатором запроса и выходом графа. Аппаратные измерения и автоматическое освобождение ещё не подтверждены.

Texture Graph GPU — Stage 38H

Инкрементальный GPU DAG теперь работает совместно с объединением pointwise-операций. Изолированные тесты пройдены.

Texture Graph GPU — Stage 38I

Инкрементальная генерация конечных текстур: неизменённые привязки сохраняются, изменённые текстуры публикуются отдельно. Изолированный тест пройден.

Texture Graph GPU — Stage 38J (частично)

Добавлены неизменяемые токены привязок и автоматический сбор при явном подтверждении ссылок нативным хостом. Сбор по умолчанию отключён; изолированные тесты пройдены.

Texture Graph GPU — Stage 38K

Подтверждённо свободные слоты процедурных текстур можно переиспользовать после GPU retirement. По умолчанию сохраняется append-only; изолированные тесты пройдены.

Texture Graph GPU — Stage 38L

Добавлены опциональные замеры отдельных вычислительных групп с идентификаторами узлов. Изолированные тесты пройдены; аппаратные замеры ожидаются.

Texture Graph GPU — Stage 38M

Добавлены Vulkan scoped timestamps с асинхронной выдачей по fence. Изолированные тесты пройдены; аппаратная проверка ожидается.

Texture Graph GPU — Stage 38N (частично)

Добавлен учёт ссылок рендерера и LENS, автоматическое переиспользование при подтверждении внешних ссылок. По умолчанию выключено; интеграционная проверка ожидается.

Texture Graph GPU — Stage 38O (частично)

Ручная и автоматическая очистка используют общую проверку ссылок Renderer3D и LENS. Неполное подтверждение и невыданные результаты блокируют освобождение; интеграционная проверка ожидается.

Texture Graph GPU — Stage 38P (частично)

Добавлены слабые ссылки на поколение изображения и проверяемый захват GPU handle с pin. Повторно занятый слот отклоняет старую ссылку. Изолированные тесты пройдены; миграция потребителей и интеграционная проверка ожидаются.

Texture Graph GPU — Stage 38Q (частично)

Кэш GPU-выходов хранит слабые ссылки на поколение и отклоняет устаревшие привязки. Аппаратная проверка ожидается.

Texture Graph GPU — Stage 38R (частично)

Renderer3D и ICB проверяют поколение текстур материалов; устаревшие привязки используют резервные текстуры. Интеграционная проверка ожидается.

Texture Graph GPU — Stage 38S (частично)

Переопределения освобождают старые pin, GI проверяет поколение, добавлен тест освобождения и переиспользования слота. Интеграционная проверка ожидается.

Texture Graph GPU — Stage 38T (частично)

LENS владеет снимками attachments; процедурные текстуры изолированы от файлового кэша и дедупликации. Интеграционная проверка ожидается.

Texture Graph GPU — Stage 38U (частично)

Picking, VT feedback и статический impostor проверяют поколение привязки. Добавлены регрессии устаревшего слота; интеграционная проверка ожидается.

Texture Graph GPU — Stage 38V (частично)

Проверены привязки VIVID Sculpt и TerraWeave; offline bake и Wardrobe не копируют живые GPU-ресурсы. Интеграционная проверка ожидается.

Texture Graph GPU — Stage 38W (частично)

Нативный scoped-доступ удерживает read lease и pin; HLOD, material palette и экспорт защищены от переноса живых процедурных поколений. Интеграционная проверка ожидается.

Texture Graph GPU — Stage 38X (частично)

Client и Editor читают GPU-выходы через scoped-доступ; Studio/MCP получает имена доступных выходов без GPU handles. Интеграционная проверка ожидается.

Texture Graph GPU — Stage 38Y (частично)

Аудит raw-ссылок, проверка двух рендереров до удаления CPU replay, единый сценарий приёмки. Автоматическая сертификация пока выключена.

Texture Graph GPU — Stage 38Z (частично)

Scoped ModelReadLease для штатных читателей Model, без удержания через мутации.

Texture Graph GPU — Stage 38AA (частично)

Защита транзакций публикации и teardown при активных читателях; сохранение pending hot reload.

Texture Graph GPU — Stage 38AB (частично)

Защита от повторного входа в callback и ранняя проверка shutdown хостов.

Texture Graph GPU — Stage 38AC (частично)

Безопасное завершение HostedClient, восстановление контекста и scoped индексация источников.

Texture Graph GPU — Stage 38AD (частично)

Учёт страниц без Model-указателей, поколения GPU и диагностика отложенных клиентов.

Texture Graph GPU — Stage 38AE (частично, приёмка)

Учёт материалов вложенных моделей при освобождении текстур и граница безопасной сертификации.

Texture Graph GPU — Stage 38AF (исправление, проверка)

Исправление линковки теста replay на Mac без расширения зависимостей snapshot.

Texture Graph GPU — Stage 38AG (исправление, проверка)

Подключение владельца NativeRegistrar к тесту camera_client_adapter.

Texture Graph GPU — Stage 38AN (Metal offscreen PASS)

Исправление аппаратных Metal timestamp-маркеров после 30/31 тестов на M3 Ultra. Stage 38AJ: регистрация CPU-проверки batching в CTest, подготовка 32 тестов; сводка Mac CTest от пользователя: 32/32 прошли; полный лог и SHA ожидаются. Сборка MCP и аудит реестра через stdio: 343 функции, 13/13 групп; GPU в редакторе ещё не проверен. Stage 38AL: исправление TypeScript и конфликта имён модулей на macOS; сборка ожидается. Stage 38AM: переработка интерфейса генератора; подключение GPU owner HTML5 ожидается. Stage 38AN: подключён native offscreen Metal owner Studio; сборка и аппаратная проверка ожидаются. Mac offscreen CTest 1/1 PASS, 1.70 с; проверка Studio ожидается.

Что позволяет делать

  • Сделать свой материал воды, лавы или голограммы без программиста шейдеров.
  • Запускать один граф на Metal, WebGL и десктопе.
  • Дать агенту менять внешний вид игры безопасно.
