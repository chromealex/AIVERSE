    Studio — редактор теперь и для Windows

    AIVERSE Studio собирается под Windows: тот же интерфейс, сцена, кисти и Play, что на Mac, работают через WebView2 и Vulkan. Mac и Windows делят одно ядро редактора, поэтому новые возможности появляются сразу на обеих системах.

    На Windows Studio — это приложение AiverseStudio.exe. Интерфейс тот же, что на Mac: рабочие пространства, панели, хаб проектов и экран загрузки. Окна Scene и Game рисует движок через Vulkan прямо поверх своих панелей, без копирования кадров через браузер.

    Всё, кроме окна, системных диалогов и ввода, у Mac и Windows общее: открытие проектов, выделение и трансформации, кисти рельефа, тайлов, полей, объектов, дорог и рек, Play, превью ассетов, панель агента. Сцена на обеих системах рисуется в отдельном потоке рендера, поэтому интерфейс не ждёт кадра.

    Собрать редактор на Windows можно скриптом studio_windows.cmd в корне репозитория. Для работы нужны WebView2 Runtime — в Windows 11 он уже встроен — и драйвер с поддержкой Vulkan.

    Заодно в обоих редакторах текст из консоли теперь можно выделять и копировать, а долгие операции больше не обрываются ошибкой ожидания.

    Проверено
    На Mac редактор на общем ядре проверен на экране: сцена с потоком рендера, выделение объектов, гизмо, меню правки. Версия для Windows собирается в готовое приложение, но на Windows ещё не запускалась.
    Ограничения
    На Windows пока нет плавающих окон панелей, перетаскивания файлов из Проводника и ассетов в сцену, рамки устройства в окне Game и запасного режима без Vulkan. Первый запуск на настоящей Windows ещё впереди.

    Окно Catalog в Studio и пакеты через MCP

    В Studio появилось окно Catalog: поиск по каталогу пакетов, карточка пакета и установка в открытый проект одной кнопкой. Агенты делают то же через MCP-команды package_*.

    Окно открывается в рабочих пространствах Look и Publish или через поиск команд. Список показывает раздел, размер и версию; установленные пакеты отмечены. В карточке — описание, версия, минимальная версия движка, лицензия, куда пакет ставится и какие пакеты придут вместе с ним. Кнопка Install ставит пакет с зависимостями, Remove убирает его файлы.

    Если у пакетов проекта пропали или изменились файлы, окно предупреждает и одной кнопкой восстанавливает их из aiverse.lock.

    Для агентов: package_search, package_info, package_status, package_add, package_remove, package_install и package_skill — те же действия на открытом проекте.

    Проверено
    Окно показано в браузерном предпросмотре Studio с демонстрационными данными; MCP-команды собраны в редакторе на Linux.
    Ограничения
    В нативном Studio на macOS окно ещё не проверялось. Превью пакетов подгружаются с GitHub и без сети не показываются.

    Панель «Сборка» в Studio

    Собрать игру под нужную платформу и оценить размер её контента теперь можно прямо из Studio, во вкладке Publish.

    Панель показывает название, версию и ориентацию игры, список платформ (macOS, iOS, Android, Web, Windows, Linux) с отметкой уже собранных и выбор Release или Debug.

    Для выбранной платформы видно, какие инструменты есть, каких не хватает и какие Studio поставит сама. Кнопка «Оценить размер» собирает только пакет контента и показывает его размер и самые тяжёлые файлы. Лог сборки идёт вживую, готовую сборку и лог можно открыть в Finder.

    Несохранённый проект Studio не соберёт молча: сначала предложит сохранить.

    Проверено
    На Mac проверены таблица инструментов и оценка размера на копии шаблона Lua Lab.
    Ограничения
    Полная сборка под платформу из панели ещё не прогонялась. Брендинг и аудит ассетов пока только в старом редакторе.
