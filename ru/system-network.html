Сеть и сервер

Мультиплеер без кода игры

По сети ходят только команды: симуляция одинакова у всех. Есть rollback lockstep, сервер с матчмейкингом и отдельная модель для серверных миров с физикой.

Документация системы

Что входит

Rollback lockstep

Клиент играет вперёд со своими командами, при расхождении откатывается к снимку и пересчитывает. Опоздавший игрок не тормозит остальных.

Выделенный сервер

Комнаты, очереди с Elo, боты для заполнения, сверка контрольных сумм, повторы, переподключение и зрители.

UDP и WebSocket

Свой слой надёжности поверх UDP на телефонах и ПК, WebSocket для HTML5.

Мобильные бои

Зашифрованный UDP по билетам, смена сети без разрыва, предсказание героя и сглаживание поправок, возврат из фона.

Replica

Сервер считает мир сам, клиенты получают дельты только того, что рядом, в пределах бюджета трафика.

Что позволяет делать

  • Сделать сетевую игру, не написав ни строчки сетевого кода.
  • Запустить сервер в Docker: ему не нужен контент игры.
  • Решать исход матча на сервере, даже если все вышли.
