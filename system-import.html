Engine systems / Import from Unity and Godot

Import from Unity and Godot

Moving a project from another engine

The importer moves scenes, prefabs, models, particles and animations; the rest goes into a report for an agent.

System docs

What is inside

Scenes and prefabs

A scene becomes a map, a prefab an object type, component fields become data.

Materials and shaders

URP materials and Shader Graph become engine materials; textures are compressed per platform.

Animation

Clips, Mecanim controllers, layers and blend trees.

Particles and UI

ParticleSystem and VFX Graph into effects, uGUI screens into RmlUi, localization.

World

Terrain, spline roads and scene meshes.

Report

Every item is marked exact, approximate or not transferred. Re-importing keeps your edits.

What it lets you do

  • Move a mobile game from Unity and carry on here.
  • Hand C# logic to an agent to port into Lua or C++.
  • Import a Godot project with the same tool.
