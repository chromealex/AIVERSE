# Библиотека материалов Shader Graph

Девять стартовых PBR-пресетов: известняк, базальт, красная и синяя ткань,
сталь, латунь, медь, воск и свечение свечи. Оригинальные графы без внешних ассетов.
Это базовые свойства поверхности, без текстурной детализации, SSS и sheen.

Из корня репозитория:

```sh
python3 tools/renderbench/install_material_library.py --project /path/to/game
```

Проект должен содержать `game.json`. Установщик добавляет графы `shaders/sg_*.json`
и снимки в `materials.json`, сохраняя остальные материалы и поля файла.
Исходный файл сохраняется как `materials.before-shader-library.json`.
Совпадения имён и существующая резервная копия останавливают установку;
перезапись не поддерживается. При ошибке диска установка может быть частичной.

Откройте проект заново в редакторе. В **Graphics → Shader Graph** выберите
граф `sg_*`. Узлы `tint`, `roughness`, `metallic` и `emission` редактируются отдельно.
После изменения сохраните граф и примените его к одноимённому материалу:
материалы хранят снимок графа, а не живую ссылку. Назначьте материал модели
через библиотеку материалов (MCP: `material_apply`).

Цвета узлов заданы в линейном пространстве. `input × tint` сохраняет базовую
текстуру модели и её альфу; граф не меняет режим прозрачности модели.
Каждый пресет содержит 6 узлов, без дополнительных выборок текстур.
Свечение — HDR emission; bloom настраивается отдельно и сам материал
не создаёт источник света для соседних объектов.

## Проверка галереи

Соберите `aiverse_hdr_gl` и `aiverse_hdr_scene` с включёнными HDR tests.
Запускайте исполняемый файл с переменными:

```sh
AIVERSE_MATERIAL_LIBRARY="$PWD/examples/shader_graph/material_library/materials.json" \
AIVERSE_HDR_CAPTURE=/tmp/material-gallery.ppm /path/to/aiverse_hdr_scene
```

`aiverse_hdr_scene` использует нативный backend (Metal на macOS),
`aiverse_hdr_gl` — GL. Слева направо, сверху вниз: известняк, базальт,
красная ткань; синяя ткань, сталь, латунь; медь, воск, свечение.
Галерея проверяет реальные скомпилированные графы в HDR с bloom.
