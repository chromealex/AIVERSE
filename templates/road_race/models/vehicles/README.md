# Trucks (Kenney, CC0)

`truck_red.glb`, `truck_green.glb`, `truck_yellow.glb`, `truck_purple.glb` and the shared `Textures/colormap.png`
are the vehicle models of Kenney's Starter Kit Racing (https://github.com/KenneyNL/Starter-Kit-Racing,
`models/vehicle-truck-*.glb`, commit 2f2e5f2646dd; 3D models CC0 1.0, kit code MIT). Renamed only; one shared
texture for all four (392 KB in all). Nodes used by the game: `body`, `wheel-front-left`, `wheel-front-right`,
`wheel-back-left`, `wheel-back-right` (forward +Z, wheel radius 0.3 m, view scale 0.4 in rules.json: 1.6 m per model metre, 4 m per cell).
