Engine systems / Game UI

Game UI

Menus and HUD in HTML and CSS

Menus, the HUD, the minimap and pause are RmlUi documents in markup and styles, not code.

Development article

What is inside

HTML and CSS

.rml markup and .rcss styles; a game replaces any file with its own.

Skins

Colours, borders and fonts per game; a portrait layout for phones.

Scale

Sizes in dp, bigger buttons on touch screens.

Languages

Texts are keys, switching the language reloads the documents.

On-screen keyboard

Its own keyboard with layouts for input fields on phones.

What it lets you do

  • Restyle a whole game with one stylesheet.
  • Translate a game into any language without touching markup.
  • Let an agent lay out screens like web pages.
