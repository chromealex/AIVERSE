How to install

A package is copied into the project folder; its version and file hashes go to aiverse.lock. Downloads are kept once per computer.

python3 tools/pkg/aiverse_pkg.py search terrain
python3 tools/pkg/aiverse_pkg.py add terrain-pbr --project ~/Games/MyGame

Add your package

Anyone can offer a package: a pull request to the catalog repository, reviewed by the owner. After the merge it appears here and in the engine by itself.

  1. Fork AIVERSE-PACKAGES and create the folder <category>/<id>/.
  2. Write aiverse.package.json: English title and summary, translations as title-ru, summary-de…, licence, minEngine, install.mount.
  3. Add README.md and a preview.jpg (a real engine frame or the asset itself).
  4. Put the files into files/, up to 2 GB. The owner accepts the pull request with the label accept: the files become a release archive and never enter the repository history. Textures of another package are not copied: depend on it.
  5. Run python3 tools/catalog.py check (0 errors) and open a pull request.
