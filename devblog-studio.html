    Additive materials in Studio

    The material library offers two additive modes: alpha weighted and unweighted. The selected mode is saved with the material.

    Open Materials, select a material, and set Alpha mode to Additive (alpha weighted) or Additive (unweighted). Apply & save writes the mode to materials.json; Reload retains the choice.

    The same values are available through material_set in MCP. An invalid mode name is rejected before the file is written.

    Verified
    Both modes were saved and reloaded in native macOS Studio. MCP also read the materials after a server restart.
    Limitations
    Material library edits are not part of MapDoc Undo. Windows has not been verified. This native editor workflow has no standalone browser demo.

    Fit impostor cards to the alpha mask

    The Models panel previews each card boundary before exporting the proxy.

    Texture Graph GPU maps on a scene model

    Studio can apply Texture Graph maps to a selected material on a loaded model for the current session.

    Open Apply to Scene model in the Texture Graph panel and refresh the model list. Select a model and material, then choose Generate and apply GPU maps to compute the maps and send the textures to the renderer.

    Inspect the graph in the flat preview and on a lit PBR sphere. Both captures below use the same graph on an Apple M3 Ultra running Metal.

    Verified
    Native Mac Studio verified application to a model material, cancellation, preview recovery and PBR rendering.
    Limitations
    The model material change lasts for the current Studio session. The native workflow has no interactive browser demo.

    Donestudio-workspace-redesign · 7c1b741c2

    Finding windows and working in narrow Studio panels

    Find any panel from the Window menu. Scene tools, forms and lists adapt to the width of their dock.

    Choose Find Window from the Window menu, type a panel name and press Enter. An open panel takes focus. The arrow keys switch between tabs in a dock, and Home and End select the first and last tab.

    In a narrow Terrain panel, brush controls wrap onto another row. Editing fields stay visible and each operation has an expandable technical description. In Assets the folder tree moves above the files. In Scripts the file list moves above the editor.

    Verified
    The screenshots show the Survivors project in Studio on macOS, including the scene, Terrain brush settings and window search.
    Limitations
    Native Windows verification is pending.
  5. Nov 25, 2026
    In progressfeature/aiv20261123_feature_gate · 911e3ceba

    Inspect regions and entities during local Studio Play

    World Explorer shows which regions own the entities in a running world. Pause and step to choose the tick to inspect.

    Open a map in an actor project and start Play. Enable regionOwnership in the project rules to expose the ledger. After stepping, refresh World Explorer. The snapshot includes the tick, session epoch and entity count for each cell.

    Select an entity in Runtime to inspect its components. Supported local games allow health or energy edits while paused. The simulation profiler displays tick durations and per-system timings.

    On supported maps, Play Mode Review previews changes and applies the selection as one undoable edit. Feature Readiness displays the project's delivery checks.

    In Roads, enter the entity count, desired update period and maximum visits per tick to see whether the simulation can revisit each entity in time. When saving a Shader Graph edit, Studio checks the original asset version.

    Verified
    Studio on macOS showed two entities in two regions of the streamed project. On a separate map, the review identified eleven removals and undo restored the original map.
    Limitations
    These panels run in the native editor and are shown in Studio captures. Map change review uses GameCore. Actor sessions support ledger inspection.

    Nodes and connections in Shader Graph and SpectraFX

    Select a node to highlight its connections. Material nodes show their constants, and dashed wires identify SpectraFX value links.

    Editable volume models in Studio

    Define a solid with a tree of fields. Adjust a cylinder radius to widen a bore, save its editable source and export a GLB.

    Combine, subtract and intersect volumes in the model graph, add noise and sample a density texture. The project stores the editable source parameters.

    Verified
    The Studio panel saved an edited cylinder center. Increasing the bore radius rebuilt the mesh, and undo restored the original GLB.
    Limitations
    The source field uses a grid resolution of 4 to 24 along each axis. Fine details can show sampling artifacts.

  8. Nov 22, 2026
    In progressmain · 5a3df7eff

    Studio, the editor, now for Windows too

    AIVERSE Studio builds for Windows: the same interface, Scene, brushes and Play as on the Mac, running on WebView2 and Vulkan. Mac and Windows share one editor core, so new features reach both systems at once.

    On Windows, Studio is the AiverseStudio.exe application. The interface is the same as on the Mac: workspaces, panels, the project hub and the loading screen. The Scene and Game views are drawn by the engine with Vulkan right over their panels, with no frame copying through the browser.

    Everything except the window, system dialogs and input is shared between Mac and Windows: opening projects, selection and transforms, the terrain, tile, field, object, road and river brushes, Play, asset previews and the Agent panel. On both systems the Scene renders on its own render thread, so the interface never waits for a frame.

    To build the editor on Windows, run studio_windows.cmd at the repository root. It needs the WebView2 Runtime (built into Windows 11) and a Vulkan-capable driver.

    Along the way, Console text can now be selected and copied in both editors, and long operations no longer fail with a timeout error.

    Verified
    On the Mac the editor on the shared core was checked on screen: the Scene on its render thread, object selection, gizmos and the Edit menu. The Windows version builds into a complete application but has not been run on Windows yet.
    Limitations
    Windows does not have floating panel windows yet, nor dragging files from Explorer or assets into the Scene, the device frame in the Game view, or a fallback without Vulkan. The first run on a real Windows machine is still ahead.

  9. Nov 22, 2026
    In progressfeature/aiv20261122_catalog_studio

    Catalog window in Studio and packages over MCP

    Studio has a Catalog window: search the package catalog, see a package and install it into the open project with one button. Agents do the same through the package_* MCP commands.

    The window opens in the Look and Publish workspaces or from command search. The list shows section, size and version; installed packages are marked. The card shows the description, version, minimum engine version, licence, where the package goes and which packages come with it. Install adds the package with its dependencies, Remove takes its files out.

    When the project's packages have missing or changed files, the window warns and restores them from aiverse.lock with one button.

    For agents: package_search, package_info, package_status, package_add, package_remove, package_install and package_skill do the same on the open project.

    Verified
    The window is shown in the Studio browser preview with demo data; the MCP commands were built into the editor on Linux.
    Limitations
    The window has not been checked in the native macOS Studio yet. Package previews load from GitHub and do not show offline.
  10. Nov 21, 2026
    Donemain · ef80a6525

    The Build panel in Studio

    Building a game for a platform and estimating the size of its content now happens right in Studio, on the Publish tab.

    The panel shows the game name, version and orientation, the platform list (macOS, iOS, Android, Web, Windows, Linux) with already built ones marked, and Release or Debug.

    For the selected platform it shows which tools are present, which are missing and which Studio can install itself. "Estimate size" builds only the content pack and lists its size and heaviest files. The build log streams live; the finished build and the log open in Finder.

    Studio never builds an unsaved project silently: it offers to save first.

    Verified
    On a Mac the tool table and size estimate were checked on a copy of the Lua Lab sample.
    Limitations
    A full platform build from the panel has not been run yet. Branding and the asset audit are still in the old editor only.
