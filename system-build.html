Engine systems / Builds and platforms

Builds and platforms

One command, a store build

aiversebuild makes an .app, an Xcode project, Gradle/APK, web and an .exe, installs the build tools and draws the icons.

System docsDevelopment diary · 5

What is inside

Six platforms

iOS, Android, web, Windows, macOS and Linux; Metal, GLES3/WebGL2, GL 3.3 and Vulkan.

Resource packs

Compressed .rpak packs, split builds and content download.

Build tools

Checks and installs the SDK each target needs.

Icons and splash

Icons and the loading screen are generated for every platform.

Store and ads plugins

App Store, Google Play, RuStore, Yandex Games, Steam, AdMob, AppLovin and more; a build carries only the chosen ones.

Engine modules

Unused parts of the engine are left out of the client to shrink the build.

What it lets you do

  • Ship a game to stores without a separate build project.
  • Build the Windows version on a Mac or Linux.
  • Keep the web build size under control.
