Engine systems / Baked lighting

Baked lighting

Global illumination with no runtime cost

Its own path tracer bakes lightmaps for static objects and a probe grid for everything that moves.

System docs

What is inside

Lightmaps

Bounced light on buildings and terrain; the second UV set is unwrapped automatically.

Probes

A probe grid lights units and projectiles with the same light as the scene.

Mixed mode

The sun stays realtime, bounces are baked; shadowmask and subtractive modes like Unity's.

No needless rebakes

A hash of everything that went into the bake: unchanged scenes are skipped.

Window and MCP

Quality, density and bounces in the Light baking window or by agent commands.

What it lets you do

  • Get soft bounced light on weak phones.
  • Bake a map with one button or one MCP call.
  • Mix baked light with a dynamic sun.
